المشروع تم تحويله من فورم تسجيل طلاب إلى نظام Feedback مجهول.

1) افتح Supabase > SQL Editor.
2) انسخ وشغّل محتوى SUPABASE-SETUP.sql.
3) ارفع كل ملفات هذا المجلد إلى نفس مكان الموقع القديم.
4) صفحة الطالب: index.html
5) صفحة الأدمن: admin-ibrahim-shamy-control-x72k9.html

مهم: صفحة الأدمن تعمل بالرابط فقط كما طُلب. هذا مناسب للإخفاء وليس حماية أمنية حقيقية، لأن السماح للـ anon بقراءة الجدول يعني أن من يفحص كود الموقع يمكنه الوصول للبيانات. للحماية الحقيقية يلزم تسجيل دخول أو Backend/Edge Function بسرّ خاص.
